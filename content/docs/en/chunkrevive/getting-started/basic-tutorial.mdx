## Essential commands

| Command | Purpose |
| --- | --- |
| `/cr reload` | Reload configuration and messages. |
| `/cr mark` / `/cr unmark` | Add or remove chunks from the target set. |
| `/cr reset` | Process targets through the configured strategy. |
| `/cr regen` | Regenerate chunks immediately. |
| `/cr delete` | Delete chunks for later native generation. |
| `/cr prune` | Prune complete regions. |

See the full [command reference](../../features/commands).

## Reset your first chunk

Use `F3+G` to see chunk borders, stand in the intended chunk, then run:

```text
/cr reset here
```

Follow the confirmation prompt. For delete-based reset plans, move well away from the target (or leave the server) and wait for the chunk to become cold. When it is loaded again, the server generates fresh terrain.

To process the current structure or biome instead:

| Command | Purpose |
| --- | --- |
| `/cr reset here struct` | Reset the current structure. |
| `/cr reset here biome` | Reset the current biome region. |

## Mark your first chunk

```text
/cr mark here
```

For the current structure or biome:

| Command | Purpose |
| --- | --- |
| `/cr mark here struct` | Mark the current structure. |
| `/cr mark here biome` | Mark the current biome region. |

<Callout type="info" title="Tip">
  `/cr mark follow` toggles automatic marking of chunks you walk through. `/cr unmark follow` similarly toggles automatic unmarking.
</Callout>

## Reset every world

First mark generated chunks in every world:

```text
/cr mark fullmark all
```

After the scan completes, review the plan and run:

```text
/cr reset all all
```

Use this only after testing on a copy and confirming that your world policy allows every target world.
