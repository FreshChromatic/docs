---
title: 重生特定生態域
description: 依生態域 ID、範圍或玩家目前所在的連續生態域選取並處理區塊。
---

## 依 ID 掃描世界

```text
/cr mark biomefull <world> <biomeIds>
```

多個 biome ID 依命令提示使用逗號分隔，例如：

```text
/cr mark biomefull resource_world minecraft:desert,minecraft:badlands
```

## 限制在半徑內

```text
/cr mark biomeradius <world> <biomeIds> <radius> [x] [z]
```

## 依玩家目前生態域

```text
/cr mark here biome
/cr regen here biome
```

`regen here biome` 會偵測、建立目標並立即重生；目標數量達到設定門檻時需要確認。

## 取樣模式

- `CENTER`：只比對區塊中心，速度較快。
- `ANY_OF_16`：在一個區塊取樣 16 個位置，更容易捕捉生態域邊界，但掃描成本較高。

連續生態域偵測受 `biome.regen.flood-fill-max-chunks` 限制。訊息顯示「已達安全上限」時，結果只包含截斷前的範圍。
