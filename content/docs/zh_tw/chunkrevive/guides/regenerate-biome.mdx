---
title: 重生特定生態域
description: 依生態域 ID、範圍或玩家目前所在的連續生態域選取並處理區塊。
---

## 依 ID 掃描世界

```text
/cr mark biomefull <world> <biomeIds>
```

多個 biome ID 依指令提示使用逗號分隔，例如：

```text
/cr mark biomefull resource_world minecraft:desert,minecraft:badlands
```

## 限制在半徑內

```text
/cr mark biomeradius <world> <biomeIds> <radius> [x] [z]
```

## 依玩家目前生態域

```text
/cr mark here biome
/cr regen here biome
```

`regen here biome` 會偵測、建立目標並立即重生；目標數量達到設定門檻時需要確認。
