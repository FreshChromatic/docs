---
title: 產生並套用效能調校
description: 依伺服器 CPU、Heap 與執行環境選擇 ChunkRevive 調校模式。
---

## 查看建議

```text
/cr tune
```

介面會顯示處理器、Heap、系統記憶體、執行緒、CPU 使用率及 Paper/Folia 環境。

## 預覽模式

```text
/cr tune preview optimized
/cr tune preview balanced
/cr tune preview performance
```

| 模式 | 適合情境 |
| --- | --- |
| `optimized` | 優先維持 TPS/Folia region tick，接受較長完成時間 |
| `balanced` | 一般正式伺服器 |
| `performance` | 維護時段，願意使用更多 CPU、I/O 與 Heap |

## 套用

```text
/cr tune apply <profile>
/cr tune apply <profile> --confirm
```

套用前必須沒有 Regen 或掃描工作。外掛會備份 `config.yml`，寫入重生與掃描設定並立即套用。

## 手動調整時優先觀察

- `regen.work-tile-size`：控制單一 ProtoChunk 圖大小。
- `regen.apply-batch-size`：控制每 tick 套用到 live chunks 的數量。
- `regen.thread-pool.parallelism`：生成執行緒。
- `scan.thread-pool.parallelism`：Region 掃描並行度。
- `regen.memory-safety.heap-high-watermark-percent`：停止派發新工作時的 Heap 水位。

保留 `regen.memory-safety.enabled: true`。不要同時提高 tile、執行緒和 apply batch，再以一次測試判斷穩定性。
