ChunkRevive 是為長期運作伺服器設計的地形生命週期管理插件。它能找出已探索的地形、精確標記要處理的區塊，並將它們重生或移除。

它特別適合用於資源世界、探索區域與可再生結構：在保留玩家活動區、受保護領地和你想留下的世界部分的同時，讓資源與地形保持新鮮。世界更新後，也可用它產生新版本的地形，不必手動尋找並刪除 Region 檔案。

## 功能重點

- 標記單一區塊、移動經過的區塊、指定座標或一個半徑範圍。
- 直接從 Region 檔案掃描已生成地形，適合完整世界與大型資源世界。
- 依可設定的生態域比對規則，掃描整個世界或指定半徑內的生態域。
- 除了重生區塊，也能刪除選定區塊，或在條件安全時清理完整的 Anvil Region。
- 自動追蹤結構、排程更新，並把保護範圍擴展至結構的完整占地。
- 玩家可用 `/keep`、`/keepchunk` 或 `/chunkkeep` 查詢附近受追蹤結構的保護進度。
- 依世界允許／拒絕規則運作，並可整合第三方領地保護插件。

## 運作方式

1. **找出目標**：使用手動標記、半徑／生態域掃描、全世界掃描或自動結構偵測，建立要處理的地形集合。
2. **檢查目標**：以遊戲內顯示、狀態指令和結構資訊確認標記結果。
3. **重置地形**：安全地重生選定地形；也能在設定的策略下刪除個別區塊或完整 Anvil Region。
4. **保護重要內容**：世界規則、領地保護整合、結構追蹤、確認旗標、工作區塊限制與堆積記憶體節流會貫穿整個流程。

<Callout type="warn" title="先備份並小範圍測試">
  地形重生與刪除是強力操作。首次使用時，請先在資源世界或世界副本測試，僅標記確定要變更的區塊，並在執行前檢查狀態與確認提示。
</Callout>
